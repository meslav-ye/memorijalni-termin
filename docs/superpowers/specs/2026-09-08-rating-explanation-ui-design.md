# Rating explanation UI

Date: 2026-09-08  
Status: approved

## Goal

Help players understand why their rating moved after a game.

## Behaviour

### Sažetak termina

One shared block „Kako se računa rating“ explaining team Elo + individual contribution rules (not per player).

### Profil igrača

In „Zadnje utakmice“, under each delta for that player:  
`Elo ±N · doprinos ±M (…G, …A)` when contribution can be recomputed from events.
